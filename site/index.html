Capital controls for autonomous agents

An AI agent can trade your capital. It cannot take it.

Mandate is a smart contract that holds the funds and enforces the terms on every order: which assets, what size, at what price, and how much loss is tolerated before trading halts. The agent holds a key that can do one thing. There is no function it can call that moves money out.

The problem

Delegation without custody.

An autonomous agent needs capital to be useful and needs supervision to be safe, and those requirements have been mutually exclusive. Handing an agent a wallet means a prompt injection, a model error or a compromised key is indistinguishable from a legitimate instruction, and the loss is discovered after settlement.

Policy in a system prompt is not a control. Mandate moves the constraints into the settlement path: the contract holds the assets, validates each order against its terms, and reverts anything outside them. Supervision stops being a monitoring problem and becomes a property of the venue.

Terms

Five constraints, fixed at issuance.

Set by the owner when the mandate is created and immutable thereafter. Neither the agent nor the issuer can widen them afterwards; a new mandate is required.

Price data is rejected past a configurable staleness bound. Chainlink's Arc feeds publish on a 0.5% deviation threshold with a 24-hour heartbeat.

Order path

Every order is validated before and after execution.

Pre-trade checks bound what may be attempted. Post-trade checks bound what actually happened, measured from the contract's own balances rather than the venue's return value. Any failure reverts the transaction in full.

Refusals name the constraint that rejected the order and state plainly why, so the agent can resize or wait rather than retry blindly. The same reasons are exposed through the JavaScript SDK.

Evidence

Executed against Arc mainnet state.

A single eth_call against live mainnet with a state override: the contracts are instantiated inside the call, funded, and an agent trades USDC into EURC and back through the production Uniswap v4 pool, validated against the production Chainlink feed. Nothing is broadcast, so the result is reproducible by anyone at no cost.

Integration

Three tools. No custody to arrange.

The agent connects over MCP and receives its position, the prices its orders will be judged against, and the ability to trade. Its authority is the mandate's terms — nothing is configured client-side, so a compromised agent process cannot widen them.

Venue

Arc, Circle's settlement layer, where USDC is the native gas asset and fees are approximately one cent. Chainlink publishes 32 feeds on Arc mainnet; Uniswap v4 is deployed there.

Current market

USDC/EURC is the only pool on Arc with meaningful depth today, so the reference mandate is a currency strategy. Additional assets require liquidity, not new code.
